# 1.0.1：主编辑器导出与半透明 PNG 修复

日期：2026-10-12。范围：用户要求完成的两个最高优先级问题；没有扩展到多轨合成、骨骼或特效输出。

## 修复结果

1. 主轨帧的位移、正负缩放、旋转与透明度进入生产预览、越界检查、正式 PNG/图集和清单。先绕完整源图中心执行编辑器变换，再执行地面根与公共画布对齐。帧属性进入缓存键、审核指纹和导出快照；修改后旧确认失效，过期任务不能发布。清单记录 transform，生产服务契约升级为 1.1，健康旧服务不会被抢锁或终止。
2. 合法非空半透明 PNG 可以显式审核，不要求 Alpha > 128 的核心像素。导入、人工笔刷和 GUI 空图检查均使用实际前景 Alpha。旧导入记录的 LOW_CONFIDENCE 提示在读取时兼容，原始文件和确认状态不被改写。空图、擦空及自动抠图低置信噪声仍被阻止。

独立审查补充发现：子像素缩放可以让几何前景在重采样后完全消失。已按最终渲染 Alpha 判定 empty，几何 bounds/overflow 仍检查裁切；检查与保存复用同一次渲染。对应 Python 测试先失败后通过，服务集成测试确认这种空帧不能获得正式导出批准。复审重跑原始复现，无剩余阻塞问题。

## 便携包实测

最终使用 task-owned 新目录 SpriteMotionStudio-1.0.1-r1，运行时来自独立包；从 C:\Windows\Temp 启动，PATH 仅保留 Windows 系统目录。最终证据位于 fixtures/generated/editor-export-portable-r3，并摘录到本报告目录。

GUI 实际导入三张全半透明 PNG，逐帧手动确认；用主编辑器按钮调整第一帧缩放、旋转和透明度，完成对齐和正式导出。随后 CLI 导出相同项目，核对完整清单和 PNG 摘要一致；第一帧 Alpha 最大值为 115，确实来自 128 × 0.9。另有 300 帧时间轴选择与纹理缓存预算检查。

包为 Windows x64 便携版，解压后双击 SpriteMotionStudio.exe。关闭旧版窗口和后台后再用新版打开相同工作区；新客户端遇旧 1.0 服务会提示版本冲突。个人素材与工作区不随修复包替换。

当前验证限于本机 Windows 换目录、受限 PATH 和合成素材。干净虚拟机、真实素材美术确认及 Cocos 实际播放仍未在本轮验收。源码和本地包完成后，本轮尚未提交或推送 GitHub。
