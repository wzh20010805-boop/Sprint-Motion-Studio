# Sprint Motion Studio 1.0.0

小兵动画素材工坊 P2–P5 Windows 便携版：本地 CPU 抠图与遮罩修正、统一角色画布/比例/地面基准、审核导出透明 PNG/图集/manifest/MP4/ZIP，GUI、CLI 和九工具 MCP 共用工作区。

## 下载与启动

下载 `SpriteMotionStudio-win-x64-1.0.0.zip`，解压后双击 `SpriteMotionStudio.exe` 或 `START.cmd`。无需另装 Node.js / Bun / Python。自动抠图需要通过菜单明确下载或离线导入 u2netp 模型，模型未附包。

包内附新版说明、GitHub 仓库/更新入口、此前导入的奔跑案例媒体、许可与逐文件 SHA256 清单；安装包旁附整包 `.sha256`。工作区保存在当前用户 LocalAppData，可在菜单切换，原素材保留。

仓库首页的上游截图和案例已换成本版 UI 实拍、用户此前提供的「5s奔跑视频制作.mp4」和当前 27 帧抠图动作预览。演示媒体不授予源码 MIT 许可中的再分发授权。

## 源码与依赖

应用源码可通过本 Release 的 GitHub Source code 下载。`SpriteMotionStudio-1.0.0-dependency-sources.zip` 附对应 FFmpeg 1034b144ff73、Bun 1.4.2 源码和 FFmpeg 构建配方；依赖的源码取得、WebKit 固定版本与重建方法见包内 `licenses/distribution-sources.md` 和仓库的同名说明。保留 FrameBaker 上游历史、MIT 许可和第三方 notices。

## 验证与范围

合入远端 CI 修复后，264 项仓库测试、15 项 Python 图像测试、server/web/CLI 类型检查通过。Windows 独立运行时、本地资源、换目录与受限 PATH、真实 GUI/CLI 输出一致、300 帧纹理预算及 MCP 已验证。

本版二进制未签名；干净 Windows 虚拟机和真实美术质量验收尚未完成。展示案例仍需人工逐帧检查，正式导出有审核闸门。
