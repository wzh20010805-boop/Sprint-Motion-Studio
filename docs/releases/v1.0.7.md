# 素材创意工坊 1.0.7 · Windows 便携版

本次发布包含 2026-10-12 的界面、素材库、逐帧预览和抠图/导出修复。

## 更新内容

- 中文名称改为“素材创意工坊”，首页标语改为“让创意，动起来！”，更新高饱和糖果色插图；英文名保留 Sprite Motion Studio。
- 主编辑器和场景抠图窗口支持键盘 ← / → 快速逐帧预览，保留输入框、弹窗、绘画和拖放期间的操作保护。
- 素材库按“项目 → 视频 / 照片”分区，上传可选择项目；旧素材按来源关联归类，保留跨项目复用、自定义文件夹和原件。
- 修复青色按钮光晕状态与删除特效按钮外观。
- 修复播放预览闪烁，以及历史抠图任务导致确认遮罩时先报“帧不存在”的问题。
- 主编辑器的位移、缩放、旋转和透明度统一用于生产预览与 PNG/图集导出；支持非空半透明 PNG 的人工确认。

## 下载与使用

下载 `SpriteMotionStudio-win-x64-1.0.7.zip`，完整解压后双击 `SpriteMotionStudio.exe` 或 `START.cmd`。运行时已经包含 Electron、Bun、Python 和 FFmpeg。

工作区默认保存在当前用户的 `LocalAppData\SpriteMotionStudio\workspaces\default`；菜单可选择已有工作区。升级时使用原工作区继续编辑，源素材和已保存的遮罩保留。

自动抠图需要 CPU 模型：首次使用时在菜单下载模型，或离线导入已有模型文件。本安装包不附带模型。完整使用与 CLI/Codex 接入说明在包内 `CLI与Codex接入.md`。

正式导出前需要检查并确认遮罩和当前对齐修订。统一比例决定导出尺寸，显示倍率仅放大屏幕预览；角色超出公共画布时，请调整统一比例或画布后重新预检。
