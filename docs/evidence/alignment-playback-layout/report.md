# 对齐播放时弹窗抖动

上次播放修复增加了载入文字，但状态段落为空时高度0、显示文字时高度21px。弹窗由modal-mask居中；该段落每帧显隐，使弹窗高度变化21px、顶边上下跳10.5px。帧号从1到10也使计数区宽度变化7.546875px，挤动后续按钮。

本次为 `.alignment-status` 预留1.5em行高，为 `.alignment-frame-counter` 按总帧数预留完整数字宽度、禁用换行并使用等宽数字。素材尺寸、50%显示倍率、后端对齐与审核事实未修改。

隐藏Electron有限验证：真实组件、121帧测试序列、150ms图片延迟、16ms父组件刷新；取132次几何样本，覆盖加载中/已加载、帧号9→10与播放/暂停。
