# FrameBaker 变更日志

本文按版本独立记录新增、调整及 Bug 修复。main 发布采用兼容 SemVer 格式的 `MAJOR.WEEK.BUG` 规则，详见 [VERSIONING.zh-CN.md](VERSIONING.zh-CN.md)。

## [Unreleased]

- 修复跨平台 CI 启动：Windows 私密桌面 bootstrap 描述符先明确登记当前用户为所有者，再验证受保护权限白名单；权限失败仍拒绝启动，仅返回有界诊断代码。真实管道测试使用独立工作区；CLI 转发夹具使用合规令牌并验证复用自身服务。

- 候选验收新增“确认整个动作并允许导出”：用户检查全部最终帧和播放后一次确认，原子登记每帧审核与播放，保留版本/CAS/真实审核人/幂等/撤销及交付闸门；未解决问题和需修复帧阻止整段确认。对齐窗口的协作动作确认按钮进入候选验收，不再使用旧修订确认入口。

- 修复对齐工作台播放时整个弹窗上下抖动：为载入提示预留固定行高，为帧号按总帧数预留宽度，避免提示显隐和帧号位数变化反复改变布局。

- 修复对齐工作台播放被后台刷新反复重置计时、停在第一帧：稳定制作帧列表，计时仅依赖当前帧身份和时序，等待图片加载后再推进；单帧预览只读取当前帧图像，避免每帧重复读取整段素材，并显示载入提示。

- 对齐工作台不再默认将大画布放大两倍：首次加载按512×320预览范围适配，512×640素材默认50%；增加25%/50%/100%/200%显示倍率，并说明预览缩放不改变导出尺寸。

- 协作与验收移入独立弹窗，释放主编辑区；任务队列默认收起，支持批量隐藏提示、跨启动记忆和重新查看。候选验收增加返回导出按钮、冻结时长说明及播放前图像缓冲，避免逐帧请求解码造成播放停顿。

- 修复 maker MCP/CLI 的返工与时序设置被拒绝为 INVALID_REQUEST：适配层只将 request_key 传入严格操作身份契约，保留原始负载、内容冲突检查与幂等重放。

- 修复播放条随帧号位数变长变短、居中位置左右跳动：按总帧数预留计数宽度，同时为FPS数值预留三位宽度，保留拖拽和范围预览。

- 修复角色双腿之间被前景和阴影封闭的近纯色背景无法清除：批量抠图支持逐帧背景点，CLI/HTTP/共享recipe及maker MCP同步接通，缓存升级v5；保留未标记的同色围裙、袜子与原始图像。

- 主编辑器播放预览的 FPS 滑杆上限从24提高到120，与已有后端动作帧率范围一致；候选验收保留固定候选原始有理数时序。

- 真实角色批处理发现纯色背景提前加载 rembg/pymatting 导致首帧迟迟未输出：改为复杂背景才初始化模型，会话仍在同批内复用。纯色背景用现有 scipy 四邻域连通标记加速，并清除连通背景压缩噪声形成的半透明灰雾；更新缓存算法版本，保留内部浅色与分离部件。

- 增加生产1.2制作MCP/CLI与范围明确的审核HTTP接口、不可变用户原话及来源身份、完整分页、有界字节传输、原操作恢复及独立取消契约。

- 新增本机制作/审核会话隔离、受保护桌面 bootstrap、两个宿主共用握手及生产 API1.2 兼容检查。

## [0.5.0] - 2026-09-02

### 新增

- 图片素材新增基于 imageops worker 的色键抠图：支持画布吸管取色、主色色盘、0–255 切比雪夫容差、可选边缘过渡、实时预览，以及保留源图的单张或批量应用。
- 所有生成弹窗新增可选纯色垫底图：支持高对比预设色、自定义颜色与基于素材主色的自动推荐；服务端通过 ImageMagick 临时合成引用图，绝不修改源素材或项目帧。

### 移除

- 移除了参考图拆分中的目标骨架选择器：它只影响生成提示词与网格行列，下游切分、命名与绑定均不消费，且 `targetSkeletonId` 从未被服务端接收；拆分网格恢复为手动行列 + 人形默认值。

## [0.4.0] - 2026-08-20

### 新增

- 角色绑定编辑器新增项目级关节角度修正：逐骨骼基础旋转随角色持久化，并统一应用于静止姿势、所有动作及 `.fbanim` 导出，不会修改共享骨架资产。
- 新增确定性的柔性附件变形：披风等软性部件支持画布弯曲拖拽，以及静态弯曲、播放摆幅、方向、频率和相位控制。
- 新增完整人物骨骼分件表工作流：支持逐格取图、直接拖动分隔线、矩形合并、右键横向/纵向细分、质量门禁预览，以及入库前逐部件擦除编辑。
- 骨骼切分弹窗新增连通域自动检测：按不透明块逐个识别为部件单元（阅读顺序排列），避免均匀网格切穿部件；检测出的每格仍可微调、切分、合并与命名。
- 新增人形骨架语义诊断与自动组装的共享层能力及测试（尚未接入界面）。
- 骨骼绑定的素材图片选择器新增文件夹筛选，支持多级目录路径以及“全部”和“未分组”视图。
- 素材库右键菜单、REST API 与 MCP 工具新增素材重命名，并立即同步当前打开的素材视图。
- 补齐图片素材右键菜单，可直接进入剪裁、逐帧/骨骼切分、人物拆分、多动作/八方向生成、还原抠图、导入、场景分层、自动裁边、导出与删除。
- 动作事件支持输入、校验并查看可选 JSON payload，数据随 MotionClip 持久化。
- 新增 MotionClip schema v2：逐片段 cubic-bezier 时间曲线、显式无损 v1 迁移、四元数缓动 slerp、曲线编辑及 `.fbanim`/光栅烘焙兼容。
- 部件新增自由变形：绑定编辑器中可为部件启用可拖拽的控制点网格（2×2/3×3/4×4）做静态变形，动作时间轴上的 `att:` warp 轨道以同样的网格增量打关键帧；变形位图按确定性光栅化（最近邻取样）生成，合成顺序在弯曲滤镜之前，并完整支持 `.fbanim` 导出再导入。

### 调整

- 内置人形骨架及关节名称现会在骨架选择、动作编辑、画布提示、时间线和角色绑定中随界面语言切换，自定义名称仍保持用户原文。
- 优化人物分件提示词：用户指定的网格仅代表容量，允许多余透明格和超大部件占用连续矩形多格，并禁止为填满网格虚构部件或武器。
- 拖动分隔线时仅调整当前格及该边界正对的关联格，左右其他格不再随整条分隔线一起变化。
- 骨骼项目统一只输出 `.fbanim` 运行时包，移除逐帧项目兼容烘焙线路、RenderProfile 与 RasterSequence API。

### 修复

- 选中附件的变换框现会直接接管画布拖动，重叠部件不再把弯曲或变换操作错误转移到其他图层。
- 橡皮擦拖出编辑画布时现会一直擦到图片实际边界，同时质量检查不再把几乎透明的抗锯齿残留误报为分件贴边。
- 修复骨骼项目编辑器不感知动作资产保存的问题：动作页签的实时预览画板与角色页签的骨骼/绑定视图现订阅 `animation_assets_changed`，动作编辑弹窗（或其他页面）一旦保存即重新拉取当前动作、骨架与资产列表。
## [0.3.1] - 2026-08-13

### 调整

- 多图生成请求现拆为受全局队列并发数控制的独立任务；响应新增 `jobIds` 并保留兼容字段 `jobId`，每个素材生成完成后会立即刷新已打开的素材库。
- 所有动作默认提示词现根据引用角色的外形、装备与能力决定待机、移动、攻击、施法、受击及倒下的具体表现，不再预设固定动作；用户仍可通过附加描述明确指定细节。
- 视频生成提示词（提示词加强器与默认动作视频）现统一要求稍广的锁定镜头并在四边保留约 15% 安全边距，确保角色整体与完整动作轨迹始终处于画面内，肢体与道具不会在画面边缘被裁切。

### 新增

- 新增独立的轨道×步骤攻击特效单元格（支持没有图片的空格）：可实时合成预览带首尾收锋的烈焰/能量/墨痕笔迹，提供利刃/毛锋/飞白/火星/残影五种稳定纹理和只删除特效的独立操作，支持变换、跨步骤复制粘贴、撤销，并在所有动画轴的播放与导出中完成合成。
- 动画导出现可明确选择独立 PNG 序列或在浏览器画布宽度上限内自动换行的单张精灵图，两者均附带帧元数据 JSON。
- 项目导入素材时新增目录筛选、当前结果全选/取消全选及 Shift 范围选择。
- 图片素材详情新增角色 8 向图快捷生成：基于引用图锁定角色，以 3 / 2 / 3 环绕中心空格的固定 3×3 布局生成转向表；网格拆分默认使用 3×3 并跳过中心格。

### 修复

- 切换时间轴步骤或绘制特效时不再重新缩放、移动画布视角；仅首次加载、手动适应、画布尺寸变化或播放模式边界会重新适配。
- 精灵图导出现会扫描统一的不透明内容范围、采用紧凑的逐行网格，并先在独立单格画布合成，修复巨量透明空白和大图中间帧丢失。
- 从其他页面返回素材库时，常驻任务面板现会与服务端状态重新对账，补齐离开期间可能漏掉的任务状态更新。
- 加强角色 8 向图生成提示词：明确要求 3×3 每个有效格使用互不重复的完整身体朝向，避免所有格沿用引用图方向。
- 修复 multipart JSON 元数据被自动解析为对象后导致网格切分上传校验失败的问题；若所有格均失败，现会显示首个具体上传错误。
- 修复桌面端低高度视口下视频取帧工作区遮挡选帧区和提交栏的问题，并让时间轴或按钮聚焦后 `M` 取帧快捷键仍可生效。

## [0.3.0] - 2026-08-12

### 新增

- Web UI、REST API、MCP 工具、任务队列与 provider 适配器现支持按顺序选择最多 10 张引用图，并可混合素材和项目帧；OpenAI 兼容 edits、百炼、Gemini、百炼 r2v 与结构化 CLI 会下发全部引用图，单图协议则明确拒绝不支持的组合。
- 选择多张引用图时增加就地模型兼容性提示；异步 provider 失败时补充可操作的排查与降级建议，同时保留原始 provider 错误。
- 优化提示词加强模板：增加主体/动作/构图/风格/连续性结构，采用保守补全，防止把用户输入中的指令当作系统规则，并区分图片与视频生成要求。
- 增加视觉提示词示例与自动纠错重试，避免「黑骑士」等短描述被文本模型回答成百科解释或澄清问题。
- 提示词优化示例现严格跟随所选风格及图片/视频模式；切换风格或加强模型时会清除旧对比结果，避免误用上一次结果。
- 将当前引用图数量传入提示词优化，使其能按用户选择切换文生、单图编辑和 Image 1…N 有序多图关系指令。
- 增加项目级 Cmd/Ctrl+Z，可撤销成功的帧与时间轴编辑；同项目请求串行执行，轻量编辑只保存数据库快照，仅修改项目图片时保存文件快照，恢复失败会安全回滚，每个项目最多保留 50 条历史。

### 调整
