# 1.0.3：预览闪烁与删除特效按钮

2026-10-12。用户反馈：test 项目预览持续闪烁，删除特效按钮与旁边控件大小不一致。

## 根因与复现

原 test 项目有 27 帧，动作 FPS 为 18。逐张检查处理 PNG：全部 1280×720，非空，最大 Alpha 为 255。帧位移、缩放、旋转和透明度正常。原数据库只读备份至 fixtures/generated/playback-real/workspace，素材复制至该隔离目录并替换数据库内部路径；原工作区不参与写入测试。

Editor 在播放时传入 frame=null，通过 composite 展示当前步骤。旧 FrameEditor 在等待新纹理加载前销毁上一批合成精灵，解码期间画布只剩隐藏的主精灵。真实 Electron 连续播放 6 秒，1068 次 Pixi ticker 采样中 130 次没有有效可见图片精灵；没有加载错误。见 [修复前数据](before-playback.json)。

按钮使用 px-btn danger 文字样式：实际高度 36px，邻近 IconBtn 高度 28px，全局危险文字按钮的额外阴影让它更显突兀。

## 修复

- 当前合成保持显示，等新步骤的全部纹理解码完成后在同一回调替换。过期异步任务释放尚未采用的精灵；真正空单元格保持可清空。
- 进入播放期间保留有效主图和适配依据；返回编辑也等待选中图准备好，避免模式切换产生加载间隙。八项近期纹理预算继续使用原逻辑。
- 删除特效改为 IconBtn，28×28px，图标尺寸与邻近按钮一致；保留删除处理、禁用条件、悬停说明和 aria-label。
