# 对齐工作台的大画布预览倍率

用户截图中512×640画布以默认2×显示，画布实际占1024×1280 CSS像素；约480像素高的角色因此显示为约960像素，50vh预览区只看得到上半身。此前已完成的角色基准归一化与成片50%缩放方案没有同步到这个预览控制。

首次读入对齐配置后，显示倍率取 `min(2, 512 / width, 320 / height)`；本批512×640素材默认50%，预览画布256×320，人物基准240像素。提供25%、50%、100%、200%选项，特殊画布保留初始适配比例选项。界面明确说明显示倍率不改变导出尺寸；这次不修改素材、对齐配置或候选记录。

验证命令：`bun probes/desktop/run-alignment-zoom.ts docs/evidence/alignment-zoom/after`。这是隐藏的隔离Electron窗口，使用真实AlignmentWorkshop组件与本批固定PNG，HTTP只允许读取。它不是用户当前已启动窗口的截图。

- 修复前：画布1024×1280，人物基准960，完整可见false；[记录](before/layout.json)。
- 修复后：画布256×320，人物基准240，完整可见true；切换200%再回50%后保持240，9个配置输入值不变，无写请求；[记录](after/layout.json)、[验证窗口](after/layout.png)。
- `bun run typecheck` 退出0。

Windows当前后台使用启动时打包的前端，现有窗口不能仅靠页面刷新加载新源码。用户保存当前编辑后关闭素材窗口，运行该批次的“重启并打开人工审核.cmd”；它检查服务身份与活动任务，再重新加载同一工作区。
