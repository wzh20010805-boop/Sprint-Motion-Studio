目标是尽快交出可审核、可复用的完整动作资产。使用工具原有处理链；把成熟操作复用到同类素材，把新发现的阻断限制在具体动作和阶段。

## 批次开始

1. 固定一个明确的工作区，保留原件；列出素材、动作名称和用途。读取一次 `inspect_capabilities` 和相关项目／动作状态，确认实际可用接口与依赖。CLI 使用同一个 `--workspace <绝对目录>` 和 `--json`；依赖诊断才用 `doctor`。已有 MCP 定义足够时直接使用，缺字段时查询一次对应 schema，命令是 `schema`。
2. 复用同角色、同用途的画布、比例、锚点、输出格式与已确认参数，逐项保留 `user`／`preset`／`inferred` 来源。只集中询问真正缺少的主体、PNG 时长或用途约束；用户不必填写 ID、recipe 或数值问卷。
3. 建一份简短批次记录：素材哈希、预设、项目／动作／源／task／operation／job／candidate ID、阶段结果路径、耗时与实际业务调用数。成功结果是下一次的起点；参数缓存按素材和内容身份使用。

## 制作流程

首次制作或批量新动作时读取 [production.md](references/production.md)，然后按以下阶段完成：

**导入 → 完整抽帧／PNG 时序 → 整段抠图与局部修正 → 公共对齐 → 固定候选 → 全帧技术检查 → 有界视觉抽样 → 提交审核。**

- 视频默认保留整个动作的全部帧、原顺序和有理数源时长。PNG 保存自然顺序或用户清单，使用已确认 FPS／逐帧时长；PNG 没有视频 PTS。
- 一次提交整段抠图任务。已透明 PNG 先沿用已有 Alpha；修复针对具体帧和区域。动作在素材中的步态与成片中的移动位置分开处理，保持角色非对称配件方向。
- 使用当前工具返回的内容基础和遮罩版本写入。变更后采用返回的新身份；返回缺少下一次必需身份时读取一次当前制作状态。相互依赖的写入串行执行。
- 固定私有候选后运行一次完整技术检查，读取该候选唯一的采样计划。仅观察计划内最终 PNG；同一帧的源图／Alpha／背景对照计为同一帧。记录真正看到的像素、问题和未覆盖范围；无法查看就记不确定。
- 默认预算由工具计算 `B=min(12,max(1,floor(N/2)))`，用户可降低；不轮换计划扩大覆盖。内容改变后生成新候选，复用内容身份未变的真实观察证据。
- 自检完整且无技术阻断后提交固定候选，交给用户逐帧及连续播放验收。AI 抽样和技术通过不能代替人工通过。

## 减少调用与试错

- 同一批次复用能力/schema/角色预设。内容身份未变时直接使用已返回的状态、完整清单、检查结果和产物路径；需要当前审核／交付事实或出现外部编辑时才刷新对应状态。
- 需要完整帧清单时取支持的最大页（当前最多300），按游标补齐并保存；CLI 摘要不等于完整序列，读取其给出的完整 JSON 产物。
- 把同一帧的笔刷修正合成一个 `strokes` 请求；按动作提交整批处理。独立素材的信息读取可批量安排，共用队列的重处理任务按资源能力调度。
- 长任务在阶段边界等待一次，任务终态响应已给出结果时直接继续；必要轮询使用退避，避免高频状态查询。超时只结束等待。
- 遇到具体错误时先读错误及相关状态，修一个明确原因、验证受影响阶段。普通素材制作不触发整套开发评审或合成测试。相同修复连续两次无改善时保存结果并说明具体阻断。
- 每动作报告帧数、质量问题、调用数、制作／等待／修复耗时和结果路径。不同素材复杂度不能直接当速度提升证据；未经可比实测，不承诺更快或零错误。

## 反馈、恢复与交付

有人工问题或制作修改时读取 [review-and-rework.md](references/review-and-rework.md)。超时、中断、已有产物或接受后的交付读取 [recovery-and-delivery.md](references/recovery-and-delivery.md)。

- 人工审核前只提供候选审核入口、工具固定的 PNG／图集、自检证据和播放预览。此阶段不得提前生成或提供可下载的素材包／ZIP，即使命名为“草稿”“待审核”或“待复核”。
- 打包以当前选定候选在工具中完成逐帧及连续播放人工验收、存在有效接受代次为前提。用户确认尺寸（如“240px”）、要求制作或导出，以及技术检查通过，都不等于人工审核通过；制作会话不调用人工批准入口。
- 审核通过后，正式交付只复用工具登记的原交付 operation 及其结果。不得用外部脚本或手工压缩把候选另行组成素材包，替代工具的审核与交付流程。
- 尚未通过或批准失效时，报告“待用户验收”，继续提供审核入口或处理明确返工；暂不启动打包。已有未审核 ZIP 只作为历史草稿保留，不能称为正式交付或替代本次审核。保留原件、版本、成功包和失败证据。

本 Skill 随工具的 `skills/soldier-frame-studio/` 分发；也可通过本文件显式调用。仓库或发行目录中的副本不会自动成为所有 Codex 会话的已安装 Skill。已有 MCP 配置可复用；接入命令是 `<发行目录>/sfs.exe mcp --stdio --workspace <目录>`，不隐式改全局配置或安装模型。
