# Windows 1.0.8 发行验证

日期：2026-10-15。产品版本 1.0.8，生产 API 1.3；Windows x64 免安装 ZIP。发行源码见仓库 `v1.0.8` 标签。

## 验证范围

在当前 Windows 电脑使用新发行目录、隔离的用户目录和工作区执行。程序工作目录为 `C:/Windows/Temp`，PATH 仅保留 Windows 系统目录；调用发行包自带的 Electron、编译 CLI/服务、Python、FFmpeg 与离线前端资源。安装路径包含中文和空格。未使用用户实际项目进行测试。

这属于当前机器的便携运行验证，未完成干净 Windows 虚拟机、真实素材美术验收或 Cocos 游戏内验收。测试中的人工确认仅作用于隔离合成图像，不授予用户素材任何批准。

## 已验证结果

- `bun run typecheck` 和 `bun run version:check` 通过；工作区管理 12 项、服务管理/版本兼容 14 项测试通过。
- 版本工具在独立副本完成 7 项检查：CLI/桌面 metadata 和锁文件不一致均被拒绝；在副本提升补丁版本后，6 个 package、锁文件、API 示例、双语 changelog 和 README 一致。
- `scripts/verify_portable.ts` 通过：实际 Electron 窗口的 3 帧合成透明 PNG 审核、变换持久化、地面轨迹、越界检查、已审核导出、300 帧时间轴、GUI/CLI 输出与 PNG 摘要一致；无令牌访问返回 401。
- 包内 CLI 验证统一的工作区登记/选择、并发客户端复用同一实例和唯一监听端口，服务明确报告 API 1.3。
- 包内协作制作验证来源身份、Task 幂等创建、固定 3 帧候选、Pillow 技术检查和有界抽样；maker 审核返回 403，已退休审核别名返回 404。
- 包内桌面 helper 验证当前实例握手、审核 Cookie 的独立身份，以及不兼容 API 1.2 的拒绝；私有候选仍禁止审核。CLI 同样拒绝不兼容服务。
- MCP 公开的 35 个 maker 工具与能力报告一致，不包含人工批准工具。
- 明确从本机导入校验过的可选 u2netp 模型后，复杂 RGB 合成图实际调用 rembg / ONNX CPU 会话一次，生成 3 帧 `waiting_user` 初稿；模型未打入安装包。Task 取消和经鉴权的服务停止均完成，另一登记工作区未被启动。

完整本地证据保留在 `fixtures/generated/release-1.0.8/`，不随发行上传私密 bootstrap、会话 Cookie 或工作区数据库。ZIP 内的 `发行验证.json` 记录本次通过的包级检查；附件 `.sha256` 与包内 `SHA256SUMS.json` 分别核对整包和逐文件内容。

## 已观察到的限制

初次 CPU 模型测试使用了过深的隔离用户目录，Numba 临时缓存文件路径达到 262 字符，Python 写入返回路径错误；同目录短文件名写入成功。后续验证缩短隔离用户目录，并保留原始失败与路径探针证据。Windows 环境应保持用户缓存路径简短，避免超过当前系统的路径长度限制。

## 升级、许可与回退

升级前关闭旧窗口并等待任务结束；新包明确拒绝连接旧版服务，不强制终止。选择原工作区即可继续，不自动搬移或合并素材和数据库。旧 1.0.7 下载和已有回退标签保留；程序降级不自动回退数据库，恢复数据应使用升级前的完整工作区副本。数据库迁移快照位于工作区 `backups/`。

模型不附包、不隐式下载。原有运行时许可与依赖源码取得说明保留；本次补齐 Pixi 运行依赖 `@pixi/colord@2.9.6` 原始 MIT 版权和许可，已校验精确 npm 包与来源提交。
